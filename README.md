# Kallimni 🇪🇬🐰

A standalone Egyptian Arabic learning Creation for Rabbit R1. **Separate from Atlas.**

## Deployment status
**Not deployed.** This repository currently contains setup and publishing safeguards. The app package and curriculum agent are prepared locally but have not been uploaded to this repository. GitHub Pages is not enabled or verified.

## Publishing policy
- Target: one new Egyptian Arabic lesson per day, only if it passes strict validation.
- Never publish merely to meet the daily quota.
- Validate schema, unique IDs, answer correctness, dialect, transliteration, gender forms, duplicates, cultural context, and app compatibility.
- Technical validation alone does **not** prove linguistic accuracy. Hold uncertain content until independently verified by qualified evidence or a competent Egyptian Arabic reviewer.
- No automatic merges, deployments, spending, paid APIs, or changes to Atlas until those steps are verified and explicitly enabled.
- Preserve existing learning progress and offer rollback for bad updates.
